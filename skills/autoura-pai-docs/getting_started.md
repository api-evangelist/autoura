# Getting started

## Type

Getting started

## Purpose

Start your Autoura setup by using the PlanMyVisit signup form and choosing your first visit venue.

## When to use

Use this before creating any visits, stops, routes, characters, or offers.

## Knowledge base

This document is part of the Autoura knowledge base, used by the Autoura skill:

Refer to the skill for the full index and how documents connect.

## Important

This is a **getting started document**.

Do not create visits, stops, routes, characters, or offers until this step is complete.

For humans, the easiest way to begin is the PlanMyVisit signup form:

https://www.planmyvisit.to/about/signup/start

This form starts the setup process and gives Autoura the information needed to prepare the first visit.

---

## What you are doing

In this step, we are:

1. Confirming who the organisation is
2. Understanding the organisation’s connection to the place
3. Choosing the first visit venue
4. Giving Autoura enough context to prepare the setup

This creates the foundation for structured experience data in Autoura.

The human does not need to create the brand manually or learn the dashboard before getting started.

---

## Workflow

1. Complete the PlanMyVisit signup form
2. Provide the organisation or brand name
3. Provide the main contact details
4. Describe the first visit venue
5. Explain the organisation’s connection to that place
6. Add website, summary, or notes if available
7. Submit the form
8. Wait for Autoura to review suitability and connection
9. Continue once Autoura has confirmed the setup can proceed

---

## Signup form

Use this form:

https://www.planmyvisit.to/about/signup/start

The form is designed to make the first step simple for humans.

It collects the information needed to:

- identify the organisation
- understand the first visit venue
- check whether the venue is suitable
- check whether the organisation has a meaningful connection to the place
- begin the setup process without requiring manual dashboard work

---

## First visit venue

Choose the first place you want Autoura to prepare a visit for.

This should be:

- a real, clearly defined location
- relevant to the organisation
- suitable for a half-day or full-day visit
- a good example of the experience you want to support

This will be used to:

- test the setup
- establish structure
- guide future work
- make it easier to create more visits later

For guidance on selecting and creating your first visit:

- Strategy:  
  https://www.autoura.com/core/pai/docs/visit_strategy.md

- Visit configuration:  
  https://www.autoura.com/core/pai/docs/visit_config.md

## Objectives

Early objectives help guide what should happen next.

At this stage, the objective is simple:

- get the organisation started
- choose the first visit venue
- prepare the first visit properly
- make sure the setup is useful before expanding further

Objectives do not need to be perfect.

They can evolve after the first visit has been reviewed and prepared.

If no objectives are provided, Autoura will set initial objectives to guide the work.

---

## Human review

Autoura may review the signup before setup continues.

This review may check:

- whether the requested visit venue is suitable
- whether the organisation has a meaningful connection to the place
- whether the requested first visit is clear enough to work with
- whether more information is needed from the human contact

Do not continue with visit creation until this step has been completed.

---

## Checklist

- Signup form completed
- Organisation or brand name provided
- Main contact details provided
- First visit venue selected
- Connection to the place explained
- Website or summary added if available
- Autoura review completed
- Setup ready to continue

---

## Common pitfalls

- Trying to create visits before the signup step is complete
- Choosing a vague or unclear first venue
- Choosing a place with no meaningful connection to the organisation
- Starting with too many venues at once
- Treating setup as a technical dashboard task rather than a simple human onboarding step
