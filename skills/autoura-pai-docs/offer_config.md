## What this object is

An **offer** is a venue or stop-related commercial opportunity, such as a discount or promotion.

Offers may:

- incentivise visits
- drive conversion
- provide value to the visitor

---

## When to create vs reuse

Create when:

- you want to define a new commercial offer
- you need separate tracking, limits, or usage rules

Reuse when:

- the same offer structure, limits, and tracking should apply

Important:

- if you reuse an offer at the same stop, it shares the same statistics and usage limits
- create a new offer if you need different limits, tracking, or behaviour
